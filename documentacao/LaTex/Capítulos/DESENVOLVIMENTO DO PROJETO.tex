\chapter{Desenvolvimento do Projeto}
Esta seção descreve o processo de desenvolvimento do sistema web proposto para a loja \textbf{Tropical Mix}, abordando seu escopo, arquitetura, tecnologias e práticas de testes adotadas. O objetivo é apresentar de forma detalhada as etapas que compõem a construção da aplicação, desde a definição dos requisitos e regras de negócio até a validação das funcionalidades e os critérios de qualidade do sistema. A seguir, são descritos os principais componentes técnicos e metodológicos que sustentam o desenvolvimento do projeto.

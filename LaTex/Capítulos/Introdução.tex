\chapter{INTRODUÇÃO}

O avanço das tecnologias da informação tem proporcionado oportunidades significativas para empresas de diferentes setores aprimorarem seus processos operacionais e de gestão. No contexto atual, o uso de sistemas web para controle de estoque e vendas tornou-se uma necessidade para pequenos e médios empreendimentos, permitindo maior precisão nas operações e agilidade nas tomadas de decisão.

Neste cenário, o presente trabalho propõe o desenvolvimento de um sistema web para a loja \textbf{Tropical Mix}, localizada em Guarulhos, especializada na venda de insumos para máquinas de sorvete expresso e fabricação de sorvetes. O sistema tem como finalidade otimizar o gerenciamento de estoque e controle de vendas, substituindo os métodos manuais utilizados atualmente e oferecendo uma plataforma moderna, intuitiva e acessível.

O projeto visa atender às necessidades específicas da empresa, fornecendo uma solução tecnológica capaz de integrar processos, reduzir falhas humanas e oferecer relatórios de desempenho que auxiliem na gestão estratégica do negócio.

\section{Objetivos}

O principal objetivo deste projeto é desenvolver um sistema web que permita o gerenciamento eficiente de vendas e controle de estoque da loja \textbf{Tropical Mix}.

De forma específica, o sistema pretende:
\begin{itemize}
    \item Automatizar o registro de entradas e saídas de produtos;
    \item Fornecer relatórios e indicadores de desempenho para apoio à tomada de decisão;
    \item Permitir o acesso remoto via navegador, com interface intuitiva;
    \item Reduzir erros decorrentes de processos manuais de controle de estoque.
\end{itemize}

\section{Problema e Solução Proposta}

A \textbf{Tropical Mix} enfrenta dificuldades na gestão manual de seu estoque, o que pode resultar em inconsistências nas quantidades de produtos, falhas no controle de vendas e retrabalhos administrativos. A ausência de um sistema informatizado limita a capacidade de acompanhamento em tempo real e dificulta a análise de desempenho comercial.

Como solução, propõe-se o desenvolvimento de um sistema web construído com tecnologias modernas, utilizando \textbf{Python (Flask)} no \textit{back-end}, \textbf{MySQL} como banco de dados, e \textbf{React} no \textit{front-end}. Essa combinação garante flexibilidade, desempenho e escalabilidade. O sistema proporcionará controle centralizado das operações, armazenamento seguro dos dados e relatórios automatizados para gestão.

\section{Justificativa}

A modernização dos processos de gestão é essencial para que empresas de pequeno e médio porte possam competir em um mercado cada vez mais dinâmico e tecnológico. A implementação de um sistema web para a \textbf{Tropical Mix} se justifica pela necessidade de aprimorar o controle de estoque e vendas, garantindo confiabilidade e eficiência operacional.

Além disso, o desenvolvimento deste projeto possibilita aos estudantes aplicar conhecimentos teóricos adquiridos ao longo da graduação, unindo teoria e prática no desenvolvimento de um sistema completo e funcional, voltado para um caso real de negócio.

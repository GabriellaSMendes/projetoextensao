\section{Arquitetura}

\subsection{Desenho da Arquitetura}

A arquitetura do projeto refere-se a uma aplicação web. Baseando-se em tecnologias modernas e robustas, o sistema utiliza uma abordagem web, com foco no \textit{front-end} desenvolvido em React e JavaScript.

No lado do servidor, optou-se pela linguagem Python em conjunto com o framework Flask, proporcionando uma base sólida para a lógica de negócios e o gerenciamento de dados.

Para o armazenamento seguro e confiável das informações, integrou-se o MySQL como banco de dados principal.

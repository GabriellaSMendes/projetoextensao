\begin{resumo}

O presente projeto tem como objetivo desenvolver um sistema web para o gerenciamento de estoque e vendas da loja Tropical Mix, localizada em Guarulhos. A empresa atua na comercialização de insumos para máquinas de sorvete expresso e produtos relacionados à fabricação de sorvetes, demandando maior controle sobre entradas, saídas, disponibilidade de produtos e registros comerciais.

O projeto foi idealizado para atender às necessidades operacionais da loja, que realizava o acompanhamento de estoque e vendas de forma manual. Esse processo pode gerar inconsistências nos registros, retrabalho e dificuldade de acesso a informações atualizadas. Como solução, foi proposta uma aplicação web capaz de centralizar o cadastro de produtos, clientes, fornecedores e usuários, além de permitir o registro de vendas, o acompanhamento do estoque e a visualização de informações gerenciais.

A solução utiliza tecnologias como React no front-end, Python com Flask no back-end e MySQL para persistência dos dados, adotando comunicação entre as camadas por meio de API REST e troca de dados em formato JSON. A interface foi desenvolvida com foco em usabilidade, padronização visual e integração com os serviços da aplicação, buscando tornar os processos internos mais organizados, acessíveis e confiáveis.

Além de contribuir para a digitalização dos processos da Tropical Mix, o projeto possibilitou aos estudantes a aplicação prática de conhecimentos adquiridos ao longo da graduação, integrando conceitos de engenharia de software, banco de dados, desenvolvimento web, gestão de projetos e documentação técnica em um contexto real de extensão universitária.

\textbf{Palavras-chave}: Sistema web. Controle de estoque. Registro de vendas. Gestão comercial. Pequenas empresas.

\end{resumo}

\begin{abstract}

This project aims to develop a web system for inventory and sales management for Tropical Mix, a store located in Guarulhos. The company sells supplies for soft-serve ice cream machines and products related to ice cream production, requiring greater control over product inflows, outflows, availability, and commercial records.

The project was designed to meet the store's operational needs, since its inventory and sales control processes were previously performed manually. This approach may lead to inconsistencies in records, rework, and difficulties in accessing updated information. As a solution, a web application was proposed to centralize the registration of products, customers, suppliers, and users, as well as to support sales records, inventory monitoring, and the visualization of managerial information.

The solution uses technologies such as React for the front-end, Python with Flask for the back-end, and MySQL for data persistence, adopting communication between layers through a REST API and data exchange in JSON format. The interface was developed with a focus on usability, visual standardization, and integration with the application services, aiming to make internal processes more organized, accessible, and reliable.

In addition to contributing to the digitalization of Tropical Mix's processes, the project enabled students to apply knowledge acquired throughout their undergraduate studies, integrating concepts of software engineering, databases, web development, project management, and technical documentation in a real university extension context.

\textbf{Keywords}: Web system. Inventory control. Sales records. Business management. Small businesses.

\end{abstract}
